# Program Guide Updates

The public Program Guide Updates page compares the current class list with the printed Program Guide for one session. It keeps showing those differences until a program matches the printed guide again.

The Admin section "Program Guide Updates — Latest Run" compares only the newest successful PerfectMind run with the run before it. A later run with no new differences replaces that list with "No new updates detected during the latest run." The public list is not cleared.

A failed or incomplete run does not replace either list, and it does not change the printed Program Guide.

The printed Program Guide for Session 2 starts as the earliest class list saved on this computer, from November 19, 2026. On the Admin page, "Save printed Program Guide" replaces that copy with the current class list. Replacing one that was already saved asks for confirmation. The replacement is stored in the app settings database, separate from the live class list, and it is kept across restarts and deploys.

The Admin page can also add an Addition, a Change, or a Cancelled program to the public Program Guide Updates list. Those items stay until they are removed. A later PerfectMind run does not remove them. If the same class is already on the list from the comparison, the Admin entry is the one shown.

Cancellation dates and notes are not treated as whole-program changes. A program counts as Cancelled only when its program status is Cancelled, or when it is added from the Admin page as Cancelled.

Course 28154, Request to Withdraw from Program, is never listed as an addition, a change, or a cancellation.

On the Admin page, Remove from list takes one addition, change, or cancellation off the Program Guide Updates list. It stays off after later runs. Put back returns that one item to the list.

Print updates, under Changes since the printed Program Guide, prints only that list. The latest run is not included, and the Admin page is not printed behind it.
